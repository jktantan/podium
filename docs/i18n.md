# 国际化（i18n）

项目用 [@nuxtjs/i18n](https://i18n.nuxtjs.org/) 管理界面语言，当前支持简体中文、英文、繁体中文。

## 目录

整个国际化配置集中在项目根的 `i18n/` 下，第三方组件库按库分文件：

```
i18n/
  config.ts                     # 语言清单、默认语言、cookie 键（唯一配置来源）
  locales/                      # 项目自己的文案，@nuxtjs/i18n 加载
    zh-CN.json
    en.json
    zh-TW.json
    demo/                       # demo 页面专属文案，PODIUM_DEMO=0 时不加载
      zh-CN.json
      en.json
      zh-TW.json
  vendors/                      # 第三方组件库语言包，一个库一个文件
    element-plus.ts             # Element Plus 映射
    vxe-table.ts                # VXE 映射 + 注册 / 切换函数
    vue-stack-tabs.ts           # vue-stack-tabs 映射 + 缺失语言补充
    vue-lite-layer.ts           # vue-lite-layer 映射 + 缺失语言补充
    index.ts                    # 聚合入口
```

运行时文件：

```
app/composables/useLocale.ts         # 语言状态 + elLocale / stackTabsLocale / liteLayerLocale
app/composables/useLayer.ts          # 统一弹层入口：语言 + 密度尺寸
app/plugins/vxe-table.ts             # 注册 VXE 语言包
nuxt.config.ts                       # vue-stack-tabs / vue-lite-layer 的语言包经 Nuxt 模块注入
app/components/global/LanguageSwitcher.vue   # 顶栏、登录页的语言选择器
app/components/global/AppearanceSwitcher.vue # 外观设置（也已多语言）
```

放置原则：

- **项目文案**放 `i18n/locales/*.json`，页面里用 `t('key')` 取。
- **demo 页面专属文案**放 `i18n/locales/demo/*.json`，由 `nuxt.config.ts` 的
  `locales[].files` 追加到基础语言包之后（深度合并、demo 优先）。
  `pnpm build:prod` 不追加 demo 文件，生产包里不会带这些文案。
  详见 [demo.md](./demo.md)。
- **第三方库语言包不复制进项目**，只在 `i18n/vendors/<库>.ts` 里做
  「项目语言 -> 库语言包」的映射，升级组件库时文案一起升级。
- **某个库缺语言时只改它自己的文件**，例如 vue-stack-tabs 的繁体补在
  `i18n/vendors/vue-stack-tabs.ts`，不会影响 Element Plus / VXE。
- 语言列表只在 `i18n/config.ts` 维护，`nuxt.config.ts` 的 locales 由它生成。

## 三个组件库的接入方式

| 组件库         | 语言包来源                                             | 切换方式                                                |
| -------------- | ------------------------------------------------------ | ------------------------------------------------------- |
| Element Plus   | `i18n/vendors/element-plus.ts`（官方包）               | `<el-config-provider :locale="elLocale">`，响应式       |
| VXE Table      | `i18n/vendors/vxe-table.ts`（官方包）                  | `registerVxeLocales()` 注册，`applyVxeLocale()` 切换    |
| vue-stack-tabs | 库内置 `zh-CN` / `en`，繁体在 `vue-stack-tabs.ts` 补齐 | `<VueStackTabs :i18n="stackTabsLocale">`，响应式        |
| vue-lite-layer | 库内置 `zh-CN` / `en`，繁体在 `vue-lite-layer.ts` 补齐 | `openLayer({ i18n: { locale } })`，由 `useLayer()` 传入 |

两个库都通过 Nuxt 模块注册：

- `vue-stack-tabs/nuxt`：`vueStackTabs.messages` 在安装时把繁体包与内置语言包合并；
  运行时语言仍由 `<VueStackTabs :i18n="stackTabsLocale">` 切换。`vue-stack-tabs@3.0.1`
  起入口声明会显式导出 `VueStackTabs`，IDE 可直接跳转模块自动注册的组件。
- `vue-lite-layer/nuxt`：`vueLiteLayer.i18n.messages` 注入繁体包；`useLayer()` 在每次
  打开时传当前语言的 `i18n.locale`。库会为每个弹层独立初始化 i18n，单层的 messages
  优先于模块注册的 messages，两者都与内置语言包合并。
- layer 模块设置 `css: false`，由 `nuxt.config.ts` 的 `css` 数组手动登记库样式，
  保证 `adapters/vue-lite-layer.css` 在库样式之后加载。

## 已接入的范围

- 布局框架：侧边菜单、页签标题、退出登录、工作台加载提示、语言选择器、外观设置
- 页面正文：登录页、首页、关于、设置、详情、权限示例、表格示例、Element Plus 示例、错误页
  （其中关于、设置、详情、各类示例属 demo，文案在 `i18n/locales/demo/`）
- Element Plus：输入框、日期/日期时间选择器、下拉框、分页、空状态
- VXE Table：工具栏（刷新 / 列设置）、分页、排序提示、空数据、加载中
- vue-stack-tabs：页签右键菜单、关闭/最大化按钮、iframe 提示
- vue-lite-layer：弹层标题栏按钮、默认 Footer、加载 / 错误提示；弹层内容组件的文案由调用方通过 props 传入
- `<html lang>`：由 `app.vue` 的 `useHead` 保持同步

示例数据里的人名（张伟、李娜等）属于内容数据，不随界面语言翻译；
部门、角色、状态等展示字段已接入语言包。

## 样式基线

项目所有组件的外观以 Element Plus 默认样式为基础：

- `adapters/element-plus.css` 只允许覆盖颜色，圆角、字号、控件高度、字体保持官方默认
- `tokens.css` 的圆角、字体、阴影、控件尺寸全部引用 `--el-*`
- `adapters/vxe-table.css`、`adapters/vue-stack-tabs.css` 的颜色、字体、圆角、尺寸
  同样引用 `--el-*`
- 外观设置的「密度」使用 Element Plus 自带的 `small / default / large` 档位，
  不再自定义像素值

## 在页面/组件里使用

```vue
<template>
  <h1>{{ t('settings.title') }}</h1>
</template>

<script setup lang="ts">
const { t } = useI18n()
</script>
```

带插槽的句子（例如权限示例里的 `<code>` / `<strong>`）用 vue-i18n 的 `<i18n-t>`：

```vue
<i18n-t keypath="permissionDemo.lead" tag="p">
  <template #permission><code>permission-demo:view</code></template>
</i18n-t>
```

新增文案时，三份语言包都要补上同名 key。

## 语言选择器的行为

- 切换后由 `@nuxtjs/i18n` 写入 cookie（`podium_locale`），刷新或下次访问自动恢复
- 首次访问按浏览器语言匹配，匹配不到时使用 `DEFAULT_LOCALE`
- 路由策略是 `no_prefix`：语言不进入 URL，正式页面始终是 `/admin/...`，demo 页面是 `/demo/...`

## 如何验证

- **Element Plus**：打开「Element Plus 示例」页，顶部可切换「项目主题 / Element Plus 默认」：
  - 项目主题：圆角、主色、控件高度来自项目设计令牌，尺寸跟随外观设置的密度
  - Element Plus 默认：圆角 4px、控件 32px、字号 14px、主色 `#409eff`，与原生一致
  - 页面覆盖表单、日期/时间、选择、开关、滑块、单选/复选、按钮、标签、表格、Tabs、
    分页、对话框、消息、通知、Loading、Alert、Empty
- **VXE Table**：打开「表格示例」页，看分页、排序提示、空数据文案
- **vue-stack-tabs**：右键任意页签，看右键菜单；看关闭/最大化按钮
- **vue-lite-layer**：打开「弹层示例」页，切换三种语言后检查标题栏按钮、默认 Footer
  和日期选择器文案；再切换明暗、主题色、密度后重新打开弹层，检查外观与尺寸

## 新增一种语言

1. 在 `i18n/config.ts` 的 `AppLocale` 联合类型和 `LOCALE_OPTIONS` 中加一项
2. 在 `i18n/locales/` 下放入对应语言包，文件名为配置里的 `file`
3. 在 `i18n/vendors/` 下给每个库补映射；某个库缺失就在该库文件里补 messages
4. 如果库本身没有该语言包，在对应 `vendors/<库>.ts` 里维护自定义包

## 已知限制

- VXE Table 的官方繁体语言包（`zh-CHT`）个别字段仍是简体（例如排序提示
  `升序：最低到最高`），属于上游语言包内容；需要完全繁体时可在
  `i18n/vendors/vxe-table.ts` 里覆盖对应字段。
- 页面示例数据中的人名不翻译。
